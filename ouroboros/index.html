Principles

Seven rules governing the protocol.

1
Autonomy with accountability — agents work independently but log everything
2
Minimal overhead — RTK for tokens, Telegram for control, Notion for memory
3
Reproducibility — every experiment has a config, seed, and commit hash
4
Cross-pollination — projects share insights, not just code
5
The loop closes — OUROBOROS.md itself gets updated as the process improves
6
Atomic updates — every file change is self-contained and non-breaking
7
Minimalism — single source of truth; delete over deprecate
