Operational Rules

Ten rules governing the protocol.

1
Loop closes — every artifact must improve the next iteration. Dead-end infra gets deleted.
2
Issues before code — create a GitHub issue before any feature. fixes #N in every commit.
3
Reproducibility — config + seed + commit hash are mandatory for every run.
4
Atomic commits — self-contained and non-breaking. Half-states don't exist; they're bugs.
5
Plan large, implement small — Opus for architecture, Sonnet subagents for code.
6
Minimalism — one source of truth per fact. Delete over deprecate.
7
Autonomy with trail — agents act freely; every action is logged, every decision is traceable.
8
Minimal overhead — every tool justifies itself by saving more time than it costs.
9
Cross-pollination — insights transfer across projects.
10
Ship or kill — three months without progress means a deadline or a funeral.
